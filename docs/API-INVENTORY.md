# Public API Inventory — @agorail-labs/scq-reference

Generated by extraction from the published artifact
(`0.6.2-experimental.1`, `dist/src/index.d.ts`) and the repository
source (`reference/src/index.ts`) on 2026-11-05, using
`reference/scripts/api-surface.mjs`. **Export-name surface is
identical on both sides: 22 value exports, 69 type exports, zero
name differences.** The divergence between published and source is
in type *contents* and behavior (see §3), not names. The
machine-checked snapshot is `docs/api/public-api.snapshot.json`;
a drift test guards the source surface in CI.

Classification key: **STABLE-CANDIDATE** (proposed for the 1.0
contract in `docs/STABLE-RELEASE-READINESS.md`), **SIMULATOR**
(supported as a test double only), **REFERENCE**.

## 2. Type exports (69)

Core contract types (`AcceptanceEnvelope`, `SubscriptionSnapshot`,
`SubscriptionChangeProposal`, `SubscriptionChangeQuote`,
`SubscriptionChangeReceipt`, `ChangeSpec`, `ChangeAction`,
`CommercialEffect`, `FinancialDimension`, `Unknown`, guarantee and
consistency types), store/coordinator types (`StoredAttempt`,
`MutationIntent`, `StoredResolution`, resolution-evidence types),
state-verification types, reconciliation types, and per-provider
record shapes. Class: **STABLE-CANDIDATE** as a group. Full list:
the snapshot file.

## 3. Published-vs-source content divergence (the real compat work)

Export *names* match; contents do not. Enumerated deltas in
`reference/src` since the published build (2026-11-02):

| Source change | Effect on consumers |
|---|---|
| #67 (Issue #64): envelope naming — `maxImmediateNetDecrease` canonical, `maxImmediateCreditDecrease` deprecated alias | **Published types contain only `maxImmediateCreditDecrease`.** Candidate accepts both spellings; both-in-one-envelope refused as ambiguous; stored records never rewritten. Migration note required — see the migration guide (Phase 6). |
| #51: append-only verified recovery (durable-store schema v5) | Candidate store migrates legacy evidence append-only; recovery cannot fabricate verification |
| #45: namespaced durable dispatch exclusion | Cross-namespace attempts cannot claim another namespace's intent |
| #70: test hygiene | No consumer-visible effect |
| #69: MSE–SCQ bridge (`MseScqIntentBridge`) | **Not exported from the package entry** — source-only, excluded from stable scope |

## 4. Not in the package (by design)

`src/live/` (Chargebee pilot) and `src/integration/` are excluded
from the published tarball by the package `files` field — verified
against the published artifact's contents in this program's
supply-chain audit. The `ScqEngine` class is internal; the supported
commit path is coordinator + adapter.
