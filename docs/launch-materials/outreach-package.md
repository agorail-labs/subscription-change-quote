## The ask (one paragraph, reusable)

Agorail is an experimental open-source pair of safety contracts for
AI-driven commerce changes — MSE for pre-dispatch admission of
multi-unit changes, SCQ for quote → commit → receipt on subscription
changes. Both are published on npm and run end-to-end against
simulators in about five minutes, with no billing credentials. The
most useful response is falsification: the evaluation kit lists
reproducible negative scenarios and the claims to attack, and
verified findings — positive or negative — are recorded publicly,
exactly as evidenced.
