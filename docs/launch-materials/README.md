  (`@agorail-labs/mse-reference@0.4.0-experimental.1`,
  `@agorail-labs/scq-reference@0.6.2-experimental.1`) running against
  simulators, verified in clean consumer projects on Node 20 and 22.
- No benchmarks, adoption numbers, endorsements, or third-party
  integrations are claimed anywhere in these drafts, because none
  exist in the public record.
- Agorail does **not** claim to provide authorization, exactly-once
  provider execution, atomic cross-provider updates, or
  production-certified billing safety. Any edit that introduces such
  a claim is a defect.
- Outputs quoted in the drafts are the actual transcripts captured
  from the published packages; the SCQ quote ID differs per run and
  is marked as such where it appears.
